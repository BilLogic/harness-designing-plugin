# Typography

> Fluent's typescale splits into **Base** (10-24px, body and UI) and **Hero** (28-68px, marketing). Sizes are numbered (200/300/400/...) — same numbering pattern as Microsoft's design system since Fabric.

export const TypeRow = ({ token, sizeVar, lhVar = 'lineHeightBase300' }) => (
  <div style={{ display: 'grid', gridTemplateColumns: '180px 1fr', gap: 'var(--spacingHorizontalL)', alignItems: 'baseline', padding: 'var(--spacingHorizontalS) 0', borderBottom: 'var(--strokeWidthThin) solid var(--colorNeutralStroke2)' }}>
    <code style={{ fontSize: 'var(--fontSizeBase200)', color: 'var(--colorNeutralForeground3)' }}>--{sizeVar}</code>
    <div style={{ fontFamily: 'var(--fontFamilyBase)', fontSize: `var(--${sizeVar})`, lineHeight: `var(--${lhVar})` }}>{token}</div>
  </div>
);

## Weights

| Token | Weight | Use |
|---|---|---|
| `--fontWeightRegular` | 400 | Body copy |
| `--fontWeightMedium` | 500 | Emphasized body, captions |
| `--fontWeightSemibold` | 600 | Buttons, nav labels, emphasis |
| `--fontWeightBold` | 700 | Hero text, prominent emphasis |

## Font families

| Token | Stack |
|---|---|
| `--fontFamilyBase` | `"Segoe UI", system-ui, -apple-system, BlinkMacSystemFont, sans-serif` |
| `--fontFamilyMonospace` | `"Cascadia Code", Consolas, "Courier New", monospace` |

## Decisions

- **Numbered scale (200/300/400/...) instead of named (sm/md/lg).** Adding a 350 between two existing sizes works without renaming.
- **Base + Hero split** — different teams own different surfaces. Hero sizes intentionally jump (28 → 32 → 40 → 68) — they're not on the Base 4-step scale.
- **Line height locked to size.** `--lineHeightBase300` is 20px (vs `--fontSizeBase300` at 14px). Don't override per-component.

## Source of truth

[`src/styles/tokens.css`](?path=/docs/1-foundations-tokens--docs) — `--fontFamily*`, `--fontSize{Base,Hero}*`, `--lineHeight{Base,Hero}*`, `--fontWeight*`.

## Agent prompt guide

> Default body → `fontSizeBase300` (14px). Caption → `fontSizeBase200`. Buttons → `fontSizeBase300` + `fontWeightSemibold`. Page title → `fontSizeBase600` (24px) or `fontSizeHero700` (28px). Marketing hero → `fontSizeHero900` or 1000. Always pair size with the matching `lineHeight` token.
