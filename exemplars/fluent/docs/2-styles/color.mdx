## Decisions

- **Numbered tiers, not semantic names.** Foreground1 / Foreground2 / Foreground3 / Foreground4 — adding a 5th doesn't require renaming the existing 4.
- **Brand and neutral are separate pillars.** A button doesn't ask "primary or secondary?" — it asks "brand-filled or neutral-filled?". Different decision.
- **High-contrast theme is a first-class swap, not a `prefers-contrast` override.** Designers can preview HC in the toolbar and ensure their layouts work in it before shipping.

## Agent prompt guide

> Brand action → `--colorBrandBackground` + `--colorNeutralForegroundOnBrand`. Neutral text → pick the tier (1-4) by hierarchy. Surface → pick background tier by depth (1 page-level, 2-3 cards, 4+ deep sections). Status → palette tokens. Always test in dark + high-contrast themes via the Storybook toolbar before shipping.
