# Button

> Fluent's button asks not "primary or secondary?" but "**how prominent?**" — five appearance values from `secondary` (default neutral) to `transparent` (no chrome at all). Independent from `size` (small / medium / large).

## Description

A click target. Five appearance × three sizes = 15 combinations. The `appearance` axis sets the visual prominence; `size` sets the height + horizontal padding + label size. Both axes are independent — large + transparent works as well as small + primary.

## All appearances

| Appearance | When to use |
|---|---|
| `secondary` (default) | Default action — neutral chrome with a thin border. The "if you don't know, pick this" choice. |
| `primary` | Single highest-emphasis action per region. Fills with `--colorBrandBackground`. |
| `outline` | Same chrome shape as `secondary` but lighter — for use on busy surfaces. |
| `subtle` | Borderless, hover-only chrome. For toolbars and dense UI. |
| `transparent` | No chrome at all. For text-button-like contexts inside other widgets. |

## Usage

```tsx
import { Button } from '@/components/Button';

// Primary action — single per region
<Button appearance="primary" onClick={save}>Save</Button>

// Secondary cancel
<Button appearance="secondary" onClick={cancel}>Cancel</Button>

// Subtle in a toolbar
<Button appearance="subtle" size="small">Filter</Button>
```

## Accessibility

- Renders native `<button>` — keyboard activation (Enter/Space) inherited
- Focus indicator uses `--strokeWidthThick` outline in `--colorBrandBackground` (Fluent v9 standard)
- Disabled state uses `aria-disabled` + `pointer-events: none` (handled by browser via `disabled`)
- For icon-only buttons, set `aria-label`

## Do's and don'ts

| Do | Don't |
|---|---|
| Use one `primary` per region | Use two `primary` buttons in the same view |
| Pair `primary` cancel with `secondary` or `subtle` | Use two `secondary` buttons stacked — pick a hierarchy |
| Use `subtle` / `transparent` for icon-only contexts | Use `primary` for navigation |
| Test in HC theme via toolbar before shipping | Hardcode hex values — use `colorBrand*` |

## Agent prompt guide

> Primary CTA → `appearance="primary"`. Cancel paired with primary → `appearance="secondary"`. Toolbar / icon-only → `appearance="subtle"` + `aria-label`. Hero CTA → `appearance="primary" size="large"`. One primary per region. Test light + dark + high-contrast themes before shipping.
