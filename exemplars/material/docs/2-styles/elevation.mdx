# Elevation

> Six levels (0-5), each with a defined shadow. M3 also supports tonal elevation (surface tint shifts) but in light mode the shadow is the dominant cue. Match level to component class, not visual intuition.

## When to use which

| Use case | Level |
|---|---|
| Static card on surface | 0 (use `surface-container-low` background instead) |
| FAB resting / navigation bar | 1 |
| Elevated card / top app bar (scrolled) | 2 |
| Modal dialog / navigation drawer | 3 |
| Lifted FAB during drag / banner | 4 |
| Stacked dialog over dialog | 5 |

## Decisions

- **6 levels is the entire scale.** No level-1.5 between levels. If two adjacent levels feel too close, the right answer is usually a surface tier shift, not a custom shadow.
- **Tonal elevation is implicit, not exposed.** In light mode, level-1 surfaces look identical to surface; in dark mode the surface tint adds visible warmth. Don't tokenize the tint manually.
- **Don't combine elevation with surface tier shifts arbitrarily.** A `surface-container-high` card with a level-3 shadow reads as "this dialog tries too hard." Pick one cue per component.

## Agent prompt guide

> Static UI on a page → level 0. FAB / nav bar → level 1. Elevated card → level 2. Modal / drawer → level 3. Don't go above level 3 unless you're stacking dialogs (rare).
