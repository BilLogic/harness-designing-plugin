## Decisions

- **Tonal pairs always come together.** Use `primary` + `on-primary`, never `primary` + `on-surface`. The on- token is luminance-tuned for the base.
- **Container variants for less-prominent uses.** `primary-container` is intentionally softer — for filled chips, light banners, surface accents.
- **Surface tiers, not opacity overlays.** Layering content uses different surface roles, not `rgba(0,0,0,0.05)`. Means dark theme works correctly without re-tuning.

## Agent prompt guide

> Action button → `primary` family. Secondary action → `secondary`. Information chrome → `tertiary`. Errors → `error`. For surfaces: page bg = `surface`, cards on the page = `surface-container-low`, modals = `surface-container-high`. Always pair the role with its `on-` token for foreground.
