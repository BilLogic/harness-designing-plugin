# Typography

> M3 typescale: 5 categories × 3 sizes (small / medium / large) = 15 tokens. Each token bundles font / size / line-height / weight / tracking.

export const TypeRow = ({ token, sample = 'The quick brown fox jumps over the lazy dog' }) => {
  const fontVar = `var(--md-sys-typescale-${token}-font)`;
  const sizeVar = `var(--md-sys-typescale-${token}-size)`;
  const lhVar = `var(--md-sys-typescale-${token}-line-height)`;
  const weightVar = `var(--md-sys-typescale-${token}-weight)`;
  return (
    <div style={{ display: 'grid', gridTemplateColumns: '180px 1fr', gap: '1rem', alignItems: 'baseline', padding: '0.75rem 0', borderBottom: '1px solid var(--md-sys-color-outline-variant)' }}>
      <div>
        <code style={{ fontSize: '0.75rem', color: 'var(--md-sys-color-on-surface-variant)' }}>--md-sys-typescale-{token}</code>
      </div>
      <div style={{ fontFamily: fontVar, fontSize: sizeVar, lineHeight: lhVar, fontWeight: weightVar }}>{sample}</div>
    </div>
  );
};

## Decisions

- **Roboto by default, replaceable per-app.** Override `--md-sys-typescale-*-font` once at the root to brand.
- **`title-medium` is 500 weight, `body-large` is 400.** Weight is part of the token bundle; never overridden per-instance.
- **`label-large` for buttons specifically.** Same size as `body-medium` (14px) but heavier weight (500) — that's what makes a button "feel" interactive.

## Agent prompt guide

> Page title → `headline-large`. Card title → `title-medium`. Body copy → `body-large` for prose, `body-medium` for dense UI. Button label → `label-large` (handled automatically by `<md-filled-button>`). Display sizes are for hero/marketing only.
