# Iconography

> shadcn projects use [lucide-react](https://lucide.dev) — a 1300+ glyph open-source set with consistent 24×24 viewBox + 2px stroke. One import, one prop API, one stroke weight. The harness ships the canonical mappings below so agents and designers reach for the same glyph for the same intent.

## Sizes — match the adjacent text

| Pixel | Type-scale equivalent | Use |
|---|---|---|
| 12px | `text-xs` | Inline status pills, dense chips, small badges |
| 14px | `text-sm` | Inline body text, secondary labels, tab labels |
| **16px** | `text-base` | **Default** — buttons, form fields, list items |
| 18px | `text-lg` | Page-level kickers, prominent UI |
| 20px | `text-xl` | Section headers, special cards |

## Convention

```tsx
import { Search } from 'lucide-react';

<Search size={16} aria-hidden />
```

- **Always set `aria-hidden`** for decorative icons. Pair with adjacent text or `aria-label` on the parent control.
- **Use `size`, not `width` + `height`.** lucide's prop is the single source.
- **Don't restyle the stroke.** 2px is the system. If you find yourself reaching for `strokeWidth`, you probably want a different icon.

## Color — inherits via `currentColor`

Icons inherit `currentColor`. To change color, change `color` on the parent — never set `stroke` directly.

## Icon-only buttons require `aria-label`

The icon alone isn't a name. Set `aria-label` on the parent `Button`; mark the icon `aria-hidden`.

```tsx
<Button variant="ghost" size="icon" aria-label="Settings">
  <Settings size={16} aria-hidden />
</Button>
```

## Agent intent → glyph lookup

When generating code that references an icon by intent rather than name (e.g., "the close icon"), use this mapping as the canonical resolution. Same intent → same glyph across the system.

| Intent | lucide name | Notes |
|---|---|---|
| Close / dismiss | `X` | Not `XCircle` (heavier) |
| Delete | `Trash2` | Not `Trash` (older outline style) |
| Settings | `Settings` | The cog wheel |
| Confirm / done | `Check` | Not `CheckCircle` for inline use |
| Warning | `AlertTriangle` | Use `AlertCircle` for info, `XCircle` for error |
| Info | `Info` | The "i" in a circle |
| Search | `Search` | The magnifier |
| Add / new | `Plus` | Not `PlusCircle` for inline use |
| Forward / continue | `ArrowRight` | Use in CTAs trailing the label |
| Expand | `ChevronDown` | `ChevronUp` for collapse |
| Edit | `Pencil` | Not `Edit` (deprecated) |
| View / preview | `Eye` | The visibility glyph |
| Filter | `Filter` | The funnel |
| Download | `Download` | Arrow into tray |
| Upload | `Upload` | Arrow out of tray |
| Avatar fallback | `User` | The single-person silhouette |
| Notifications | `Bell` | Not `BellRing` (active variant) |
| Email | `Mail` | The envelope |

If the intent doesn't map, search the lucide catalog at https://lucide.dev/icons.

## Do's and don'ts

| Do | Don't |
|---|---|
| Match icon size to adjacent text | Mix sizes inside the same row |
| Use `aria-hidden` on decorative icons | Leave decorative icons announceable |
| Use `aria-label` on icon-only buttons | Rely on the icon name alone for meaning |
| Inherit color via `currentColor` | Set `stroke` directly on the icon |
| Pull from lucide first | Bring in a second icon library |
| Use the canonical intent → glyph lookup | Pick a different glyph for the same intent in different contexts |

## Agent prompt guide

> When generating code that needs an icon: import from `lucide-react`, use `size={16}` by default, set `aria-hidden` for decorative use, set `aria-label` on the parent for icon-only controls. Never invent SVG inline. Never bring in a second icon library — if lucide doesn't have it, surface the gap. For intents in the lookup table, use the canonical glyph; consistency outranks novelty.
