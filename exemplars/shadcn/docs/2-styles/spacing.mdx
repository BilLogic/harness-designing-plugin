# Spacing

> shadcn/ui inherits Tailwind's 4px-base spacing scale. Eight steps for component-level padding, gap, and margin. The same eight tokens serve every consumer — no separate gap, padding, or margin scales.

## Padding vs gap vs margin

Same eight tokens; three different consumers. Pick by purpose.

| Consumer | Use when |
|---|---|
| **Padding** | Inside a surface (card, button, section) |
| **Gap** | Between siblings inside a flex/grid parent |
| **Margin** | Reserved — spacing between siblings is the parent's job; margin is the escape hatch when parent layout can't be controlled |

The harness defaults to `gap` over `margin` for stack rhythm — eliminates margin-collapse debugging.

## Decisions

- **4px base, no 2px steps.** Half-steps invite drift. The 8 sizes above are the entire scale; if you find yourself wanting 10px, use 8 or 12.
- **No exposed `--space-5`, `--space-7`, `--space-9`–`--space-11`, `--space-13`–`--space-15`.** Tailwind has them; we only token-expose the 8 in regular use.
- **Spacing means margin, padding, OR gap.** Same token, different consumer.
- **`gap` first, `margin` last.** Use `gap` on flex/grid parents for stack rhythm.

## Do's and don'ts

| Do | Don't |
|---|---|
| Pick from the 8 tokens | Use arbitrary px values (`p-[7px]`) |
| Use `gap` over margin where flex/grid permit | Stack `margin-top` on every child |
| Increase to next step when needing more breathing room | Add a token between two existing ones |
| Pad surfaces, not their children | Margin individual children to fake surface padding |
| Match the tier — element/card/section/page | Use `--space-12` inside a card body |

## Agent prompt guide

> Inline gap → `--space-2`. Component internal padding → `--space-3` (horizontal) and `--space-2` (vertical) for buttons; `--space-6` for cards. Layout-level → `--space-8`+. Never sample a px value from a Figma frame — round to the nearest token. Use `gap` on the parent over `margin` on children.
