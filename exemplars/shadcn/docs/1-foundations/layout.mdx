# Layout

> Four ideas: a 12-column grid, four breakpoints, a 1280px container ceiling, and a four-tier surface hierarchy (page → section → card → element). Combined, they describe every layout in the product. There is intentionally no fifth idea.

## Grid

12 columns. 16px gutter (`var(--space-4)`) at all breakpoints. Container max-width 1280px — page surfaces never exceed it.

## Breakpoints

| Name | Min width | Use |
|---|---|---|
| (default) | 0 | Mobile-first base |
| `sm` | 640px | Compact layouts, dense forms, mobile landscape |
| `md` | 768px | Default tablet |
| `lg` | 1024px | Default desktop |
| `xl` | 1280px | Wide desktop — equal to container ceiling |

There is intentionally no `2xl` — the container caps at `xl`, so wider viewports get more whitespace, not more content.

## Surface hierarchy

Four tiers stack via CSS variables. Pick by purpose, not aesthetic.

| Tier | Token | Padding | Use |
|---|---|---|---|
| **Page** | `--background` | `--space-8` (32px) | Outermost canvas |
| **Section** | `--background` (often) | `--space-6` (24px) | Logical groupings within a page |
| **Card** | `--card` | `--space-6` (24px, supplied by `CardHeader` / `Content` / `Footer`) | Discrete surface — list items, dialogs, dashboard tiles |
| **Element** | inherits | `--space-2` to `--space-3` | Individual control |

Each tier owns its own padding. When a `Card` lives inside a `Section`, the section provides the gap **between** cards, the card provides padding **within** itself.

## Stack composition rules

- **Element inside Card** — element's padding is intrinsic; the card supplies the surface.
- **Card inside Section** — the section supplies vertical rhythm via `gap`, not via card outer-margin.
- **Section inside Page** — page padding is the outermost frame; sections stack with `gap: var(--space-8)`.

This eliminates margin-collapse debugging — surfaces never margin, parents always `gap`.

## Do's and don'ts

| Do | Don't |
|---|---|
| Use `gap` on the parent for rhythm between siblings | Apply `margin-bottom` to each child |
| Cap content width at 1280px | Stretch dashboards edge-to-edge |
| Pick the surface tier by intent | Apply translucent overlays to fake an extra tier |
| Mobile-first — escalate at `sm` / `md` / `lg` / `xl` | Desktop-first with shrinking media queries |
| Let `Section` provide the gap between `Card`s | Add `margin` to cards |

## Agent prompt guide

> Picking a layout: start with the page tier, drop sections inside, drop cards inside sections, drop elements inside cards. Never reach for absolute positioning except for overlays (popovers, tooltips). Never margin a card — give the parent a `gap`. Below 640px is the default; opt into `sm` / `md` / `lg` / `xl` only when the layout needs to change.
